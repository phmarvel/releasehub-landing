    Story

Questions, answered

The usual questions before a team starts.

Does the agent merge code on its own?

No. It opens a pull request and your team reviews and merges it.

Can I see the plan before any code is written?

Yes. Every run starts with a plan that you approve.

How is it priced?

Per user, per month. See the pricing section.

Does it work in Arabic?

Yes. The site and the workspace work in Arabic and English.
