How it works

From story to pull request in four steps

No new process to learn. Write the story as you do today.

  1. 1

    Story

    Write what you need in your tracker.

  2. 2

    Plan

    An agent reads the code and writes a plan for you to approve.

  3. 3

    Code

    The agent writes the change and its tests.

  4. 4

    Pull request

    The agent opens the pull request and your team reviews it.

Features

Everything delivery needs, in one workspace

Agents do the work, your team stays in control.

  • From stories to pull requests

    Write a story and get a pull request back, with the plan and the tests behind it.

  • AI coding agents

    Agents write the tests first, then the code that passes them.

  • A Lead that runs delivery

    Ask the Lead for progress, plans and next steps in a conversation.

  • Review and merge control

    Nothing is coded before you approve the plan, and nothing is merged without your review.

  • Parallel runs

    Several stories can run at the same time, each on its own branch.

  • English and Arabic

    Stories, plans and pull requests in either language.

Tests first

Every change arrives with its proof

The agent writes the acceptance tests before the code, so the pull request shows what was asked and that it works.

  • Acceptance criteria become tests
  • Plans are approved before coding
  • Each story runs on its own branch

FAQ

Questions, answered

The usual questions before a team starts.

Does the agent merge code on its own?

No. It opens a pull request and your team reviews and merges it.

Can I see the plan before any code is written?

Yes. Every run starts with a plan that you approve.

How is it priced?

Per user, per month. See the pricing section.

Does it work in Arabic?

Yes. The site and the workspace work in Arabic and English.

Where does my code go?
